# Security policy

SignalForge is an educational, local-first lab project. Writable mode has no user authentication, so keep it bound to localhost or behind trusted access controls. The public Render demo is designed to stay read-only and uses only synthetic telemetry; do not disable its read-only setting. The app does not terminate TLS.

To report a security issue, open a private report through the repository host's security reporting feature once this project is published. Do not include real credentials, personal data, or production logs in a public issue.
